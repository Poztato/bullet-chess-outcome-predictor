# Planned Chessica extension

This directory is the entry point for phase two. There is no installable Chessica extension yet.

The intended behavior is to observe moves, maintain valid game state and session features, evaluate punishment ratings, and display model outcome probabilities. The existing model includes draws as a third class.

Read the [phase two plan](../docs/phase-2-plan.md), the [recovery audit](../docs/recovery-audit.md), and the [historical prototypes](../archive/extension-prototypes/README.md) before implementing the manifest or inference runtime.
